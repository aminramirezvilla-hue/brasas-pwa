A las Brasas — PWA de existencias
=================================

Esta carpeta YA es la app. No hay que compilar nada.

1. Súbela a GitHub Pages (rama main, carpeta /docs) o a cualquier hosting estático.
2. Abre la URL pública en el celular.
3. Instálala:
   • iPhone: Compartir → Agregar a pantalla de inicio
   • Android Chrome: menú ⋮ → Instalar aplicación

Los conteos Hay / Bajo / Falta se guardan en el teléfono (no en la nube).
